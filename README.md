# 鸣潮 · 共鸣调酒室

## Windows / Android 应用（v1.1.0）

现在同时提供独立的 Windows EXE 和离线 Android APK，保留原网站全部配方、图片编辑、搜索、采购预算和 JSON 导入导出功能。

- **Windows**：下载 `ResonanceBar-1.1.0-Windows-x64.exe`，双击打开独立窗口，不需要安装 Node.js、不需要浏览器，也不需要手动启动服务。适用于 Windows 10/11 x64。程序未购买商业代码签名证书。
- **Android**：把 `ResonanceBar-1.1.0-Android.apk` 传到手机，点击安装。支持 Android 8.0 及以上，使用手机内置 Android System WebView；若系统要求允许当前文件管理器安装该 APK，请自行确认。应用不申请互联网、联系人或广泛文件存储权限；导入图片和 JSON、导出备份均通过系统文件选择器完成。
- **离线使用**：八款初始方案和全部界面均包含在应用内，运行不依赖在线 API、电脑服务或 GitHub。
- **数据独立**：Windows 数据位于 `%APPDATA%\resonance-bar\data`；Android 数据位于应用私有目录。两端不自动联网同步。
- **迁移原网站数据**：先在原网站导出 JSON，再在新应用导入；图片、配方、参考价和制作计划随 JSON 一并迁移。旧网站目录不会被覆盖。
- **换手机 / 卸载前**：先导出 JSON 备份。Android 卸载会删除应用私有数据，更新同签名 APK通常保留数据。Windows 与手机之间通过 JSON 备份互相迁移。

本地安装包在 `release/windows/` 和 `release/android/`。源码和构建脚本可以公开上传，但 `data/`、安装包中间文件、构建工具链与 Android 签名私钥均不应提交到 Git。

### 应用构建

```powershell
npm.cmd ci
node node_modules/electron/install.js
npm.cmd run build:windows
python scripts/bootstrap_android.py
npm.cmd run build:android
```

Windows 构建使用 Electron 和 electron-builder。Android 脚本从 Microsoft 和 Google 下载便携 JDK / SDK 构建工具到 `%LOCALAPPDATA%\ResonanceBarBuild\tools`，不修改系统 Java 设置。脚本使用 Java、aapt2、D8、zipalign 与 apksigner 编译和签名，不依赖 Android Studio。

Android 签名私钥和密码文件仅保存在 `%LOCALAPPDATA%\ResonanceBarBuild\signing`，未包含在源码与安装包中。**请私下备份整个 signing 目录**；后续更新需使用同一密钥，丢失后无法无缝升级已安装的应用。不要把这个目录上传到公开仓库。

如当前网络需要 Windows 系统 CA，可在构建进程中使用 `$env:NODE_OPTIONS='--use-system-ca'`。遇到 Electron 下载连接问题，可以使用经过 npm 包内官方校验值验证的镜像，或预先安装 Electron 后通过 `--config.electronDist=node_modules/electron/dist` 打包；不要关闭 TLS 验证。

以下保留原网站的本地启动与配方说明。

中文、响应式、完全本地的角色调酒方案网站。使用 Node.js 内置 HTTP 服务和原生 HTML/CSS/JavaScript，无第三方依赖、不需要 API Key，不需要安装 npm 包。页面不加载在线字体、CDN 或远程图片。首次读取资料来源后的日常使用可离线完成。

## 启动（Windows）

需要 Node.js 20 或更新版本；本机已使用 Node.js 24 验证。

**推荐：双击项目目录中的 `启动调酒室.cmd`。** 它会在后台启动本地服务并打开浏览器；关闭启动窗口或聊天不会停止服务。重复双击会复用已运行的服务。电脑重启后请再次双击启动。后台日志保存在 `data/server.log`。

在 PowerShell 中运行：

```powershell
cd D:\AICRATE\bartender
node server.mjs
```

浏览器打开 **http://127.0.0.1:4173**。启动窗口中按 `Ctrl+C` 停止。

也可以运行 `npm.cmd start`。直接双击 `public/index.html` 无法连接数据服务，必须启动上面的本地服务。

端口被占用时：

```powershell
$env:PORT=4174
node server.mjs
```

然后打开 http://127.0.0.1:4174 。服务只监听 `127.0.0.1`，不是局域网或公网部署。

## 使用

- **角色酒单**：按基酒筛选，搜索角色、酒名、配色、口感或材料。点击杯型图或“查看配方”打开详情。
- **详情**：展示原方毫升量、制作顺序、杯型、甜度、推测口感、材料消耗成本、杯饰和笔记。“角色视觉灵感”有单独区域与资料核实说明。
- **编辑 / 新增**：修改字段；材料支持逐行添加、移除；制作步骤每行一步。单击“保存配方”写入本地数据文件。取消或按 Esc 关闭编辑会放弃该表单未保存的修改。
- **复制**：创建独立可编辑的副本，采购杯数默认为 0。
- **预览图片**：进入“编辑配方”，在“配方预览图片”中上传或替换 PNG、JPG、WebP（原图最大 10 MB），也可以移除后恢复默认杯型插画。上传后自动压缩并显示预览，点击“保存配方”后首页卡片和详情同步更新。图片嵌入本地配方文件，复制配方和 JSON 备份均包含图片；包含图片的完整备份上限 25 MB。旧版无图片的备份仍可正常导入。
- **删除**：经页面内确认后删除，删除前旧数据会自动备份。
- **采购与预算**：每款设置 0–100 杯，改变后自动保存。相同名称材料按毫升合并；可编辑每份可用容量与参考价格。新原料在被选择制作后出现于价格表，未定价时显示“待定价”，不假装成本为零。
- **复制采购清单**：复制到剪贴板；权限不可用时自动下载文本清单。
- **JSON 导入 / 导出**：导出包含全部配方、参考价格与制作杯数的备份。导入先校验，再选择“合并更新”或“替换全部”。合并以相同配方 ID 和相同材料名称匹配；同 ID 项被导入项更新，其他项保留。导入也会先备份旧文件。

## 数据保存、迁移与恢复

首次启动时从 `seed.json` 创建 `data/recipes.json`。此后所有更改保存到 `data/recipes.json`，不依赖浏览器 localStorage。刷新、重启服务、更换同一电脑的浏览器均可读取。清除浏览器缓存不会删除本地配方。

每次保存前，旧版会保存在 `data/backups/recipes-r版本-时间戳.json`。备份不会自动清理，长期大量编辑时可自行整理。建议定期用页面“导出 JSON 备份”，复制到其他位置。

恢复：优先在网站内导入旧 JSON。若当前文件损坏而服务不能启动，先停止服务并另存损坏文件，再把选定备份复制为 `data/recipes.json` 后启动。服务遇到损坏文件会停止，不会静默覆盖或重置。

迁移到另一台电脑：复制项目和 `data` 文件夹（或在新项目中导入 JSON）。同时编辑多个窗口时，旧窗口保存会被版本检查拒绝；请复制未保存的文字后刷新，再编辑最新数据。

预置方保留原毫升量；清宵、秧秧的可选原味糖浆为 0 ml，保留 0–3 ml 范围备注；绯雪石榴糖浆以原范围下限 3 ml 计价，可编辑到 5 ml。冰块另记适量，可选闪粉记入笔记。柯莱塔原文所建议的古典杯需容纳约 206 ml 液体和冰，页面补充了容量建议。

**已纠正原文的加总错误：** 八款各一杯，基酒合计 270 ml，其中伏特加 105 ml、金酒 100 ml、白朗姆 65 ml；苏打水 940 ml、乌龙茶 190 ml、蝶豆花茶 150 ml、柠檬汁 76 ml、草莓糖浆 10 ml、蓝柑橘糖浆 12 ml、石榴糖浆 8 ml。采购页从每款明细实时计算，不采用原文错误合计。

蝶豆花遇酸可能转紫，原文的冰蓝 / 浅青仅作视觉目标，不保证稳定分层。杯型 SVG 是本项目原创代码插画，不是实拍或官方立绘；当前环境未找到可复用的原始调酒图鉴图片文件。

## 成本口径

所有金额均为人民币估算，不是实时报价。初始参考价在原对话预算范围内选取合理值，可按自己的采购价修改。

- 消耗成本 = 各材料 ml × 每份价格 ÷ 每份容量。
- 包装采购预算 = 各材料向上取整的包装数 × 每份价格。
- 茶液是冲泡后的等效份量，柠檬是可用汁量，实际买干花和鲜果的收银额可能不同。
- 未扣除已有库存；不包含玻璃杯、工具、冰块、装饰、可选闪粉和运费。
- 原文 ¥173–321 是包含部分装饰和工具的首次完整采购参考，口径不同于网页的液体包装采购额。
