# 《鸣潮》角色主题调酒企划书
## ——八款角色特调 · 低成本居家制作版

这次把前面讨论的方案全部整合起来，统一配方标准、采购材料、预算、制作步骤和角色装饰设计，方便你直接照着采购和制作。

整套方案围绕你的核心要求设计：

- **角色优先：** 每杯都有对应的角色配色和标志性装饰。
- **低成本：** 尽可能共用基酒、糖浆和装饰材料，不为单杯购买昂贵的专用酒。
- **不要太甜：** 以无糖苏打水、无糖茶、少量柠檬汁为主，糖浆只负责调色。
- **可以含酒精：** 以伏特加、金酒、白朗姆酒为主，不购买昂贵的利口酒。
- **适合居家制作：** 不需要专业调酒设备，普通量杯、长柄勺和透明玻璃杯就够用。
- **造型优先：** 通过酒液分层、透明冰块、杯签、吊坠和装饰链还原角色特点。

本次整合的八款角色为：

1. 爱弥斯
2. 达妮娅
3. 清宵
4. 心
5. 秧秧
6. 秧秧·玄翎
7. 柯莱塔
8. 绯雪

其中，心的方案以你提供的红白黑礼服、银白狐耳、蓝色宝石和金色链条立绘为参考；达妮娅则采用你之前提供的粉发、冰蓝服装、金色链条和红色手套配色。

# 第二部分：一次性采购清单

以下按照每款制作一杯、共八杯估算。

## 一、基酒采购

建议购买正规渠道销售的入门级基酒，不必追求高端品牌。

| 金酒 | 200–350 ml | ¥30–50 | 清宵、秧秧、玄翎 |
| 白朗姆酒 | 200–350 ml | ¥25–40 | 达妮娅、绯雪 |

### 为什么选择这三种基酒？

- **伏特加：** 风味相对中性，适合粉蓝、深色等需要突出视觉而不希望基酒香气抢戏的配方。
- **金酒：** 带有草本和杜松子香气，适合清宵、秧秧等偏清冷的角色。
- **白朗姆酒：** 带有轻微甘蔗香气，适合达妮娅和绯雪的红蓝配色方案。

八杯合计只使用约 265 ml 基酒，因此不需要一次购买三大瓶。

# 第三部分：八款角色特调详细配方

以下配方均为单杯量。

基酒用量控制在每杯 30–35 ml 左右，主要通过茶、苏打水和少量糖浆完成造型。

**重要说明：** 糖浆用量已经尽量压低，但蓝柑橘糖浆、石榴糖浆的实际甜度因产品而异。建议第一次制作时严格按量添加，试喝后再微调。

## 01 爱弥斯｜电子幽灵

**主题：粉色长发、电子幽灵、粉蓝渐变。**

### 材料

| 材料 | 用量 |
|---|---:|
| 伏特加 | 35 ml |
| 无糖苏打水 | 120 ml |
| 无糖乌龙茶 | 30 ml |
| 草莓糖浆 | 5 ml |
| 蓝柑橘糖浆 | 3 ml |
| 柠檬汁 | 10 ml |
| 冰块 | 适量 |

### 制作步骤

**第一步：调制基底**

1. 取一个透明高球杯。
2. 加入适量冰块。
3. 倒入伏特加 35 ml。
4. 加入乌龙茶 30 ml。
5. 加入柠檬汁 10 ml。
6. 轻轻搅拌均匀。

**第二步：加入气泡**

倒入无糖苏打水 120 ml，轻轻搅拌一次。

**第三步：制作粉蓝渐变**

1. 将草莓糖浆 5 ml 缓慢加入杯底。
2. 沿杯壁加入蓝柑橘糖浆 3 ml。
3. 观察两种颜色在冰块间扩散。
4. 不要大力搅拌。

### 装饰方案

- 用粉蓝色卡纸制作像素爱心。
- 杯身可以贴少量蓝色透明胶片。
- 如果有透明果冻，可以切成小块放入杯中。

### 最终效果

粉色底层、蓝色主体、透明冰块，呈现电子感和漂浮感。

## 02 达妮娅｜绯樱鎏光

这款以你之前发来的达妮娅立绘为准：粉色长发、冰蓝色服装、金色链条、蓝色宝石和红色手套。

**主题：粉蓝渐变、金色配饰、红色点睛。**

### 材料

| 材料 | 用量 |
|---|---:|
| 白朗姆酒 | 35 ml |
| 无糖苏打水 | 100 ml |
| 无糖乌龙茶 | 30 ml |
| 草莓糖浆 | 5 ml |
| 蓝柑橘糖浆 | 3 ml |
| 柠檬汁 | 12 ml |
| 冰块 | 适量 |

### 制作步骤

1. 在透明高球杯中加入冰块。
2. 倒入白朗姆酒 35 ml。
3. 加入乌龙茶 30 ml。
4. 加入柠檬汁 12 ml。
5. 倒入无糖苏打水 100 ml。
6. 轻轻搅拌均匀。
7. 缓慢加入蓝柑橘糖浆 3 ml。
8. 最后将草莓糖浆 5 ml 沿杯壁加入杯底，形成粉红色区域。

如果红色和蓝色迅速混合，不必反复调整。可以保留柔和的渐变，而不是强求完全分层。

### 装饰方案

- 杯颈外侧固定细金色装饰链。
- 杯身中央固定一颗蓝色吊坠。
- 用红色透明胶片制作一小段飘带。
- 杯签采用粉色与冰蓝色组合。

### 最终效果

粉蓝渐变为主体，金色链条和蓝色宝石作为视觉中心，红色装饰对应手套和披帛。

## 03 清宵｜寒剑照月

**主题：冰蓝、冷白、透明冰晶、剑气。**

### 材料

| 材料 | 用量 |
|---|---:|
| 金酒 | 35 ml |
| 无糖苏打水 | 130 ml |
| 蝶豆花茶 | 40 ml |
| 柠檬汁 | 8 ml |
| 糖浆 | 0–3 ml，可选 |
| 冰块 | 适量 |

### 制作步骤

1. 提前泡好蝶豆花茶，冷却备用。
2. 将长条冰柱放入透明高球杯。
3. 倒入金酒 35 ml。
4. 加入无糖苏打水 130 ml。
5. 沿冰柱缓慢加入蝶豆花茶 40 ml。
6. 最后加入柠檬汁 8 ml。
7. 如果觉得太酸，可加入少量糖浆，但不必超过 3 ml。

蝶豆花遇酸后可能由蓝色变为紫色。如果想保持冰蓝色，可以先不加柠檬汁，试出理想颜色后再少量调整。

### 装饰方案

- 制作一根细长的剑形杯签。
- 使用透明冰柱模拟剑身。
- 杯饰以白色和银色为主，不添加复杂挂件。

### 最终效果

透明酒液、淡蓝色渐变和竖直冰柱形成清冷的视觉中心。

## 04 心｜绯雪衔珠

这杯是整套方案中最华丽的一款。

根据你提供的立绘，核心元素是：

- 银白色长发和狐耳。
- 红、白、黑三色服装。
- 胸前蓝色宝石。
- 金色链条和精致配饰。

因此不再使用普通的紫粉色渐变，而是采用**深茶色主体＋绯红底层＋蓝色宝石**。

### 材料

| 材料 | 用量 |
|---|---:|
| 伏特加 | 35 ml |
| 无糖乌龙茶 | 100 ml |
| 无糖苏打水 | 70 ml |
| 柠檬汁 | 10 ml |
| 红石榴糖浆 | 5 ml |
| 冰块 | 适量 |

### 制作步骤

**第一步：调制深色主体**

1. 取一个透明高球杯。
2. 加入冰块。
3. 倒入伏特加 35 ml。
4. 加入无糖乌龙茶 100 ml。
5. 加入柠檬汁 10 ml。
6. 轻轻搅拌均匀。

乌龙茶的颜色用来表现黑色礼服，不需要额外购买黑色色素。

**第二步：加入气泡**

倒入无糖苏打水 70 ml，轻轻搅拌一次。

**第三步：制作绯红底层**

1. 量取红石榴糖浆 5 ml。
2. 用滴管或细嘴量杯沿杯壁缓慢加入。
3. 观察糖浆在杯底形成红色区域。
4. 如果颜色不明显，可以增加至 7 ml，但不建议为了颜色大量加糖浆。

### 装饰方案

| 装饰 | 制作方法 |
|---|---|
| 白色狐耳 | 用白卡纸剪出双耳，黑色勾边 |
| 蓝色宝石 | 杯身中央固定蓝色小吊坠 |
| 金色链条 | 杯外固定细金色装饰链 |
| 红白披帛 | 用透明红白胶片制作两条飘带 |
| 深色背景 | 拍照时使用黑色背景布，突出红色酒液 |

所有金属链、亚克力吊坠和纸质装饰都应固定在杯子外侧，不要放入饮料，也不要接触杯口或饮用区域。

### 最终效果

深色主体象征黑色礼服，红色底层对应披帛，蓝色吊坠模拟胸前宝石，白色狐耳与金色链条完成角色还原。

**这款的关键是杯饰，而不是复杂的调酒技巧。**

## 05 秧秧｜风起今州

**主题：浅青色、清新、轻盈、单片羽翼。**

### 材料

| 材料 | 用量 |
|---|---:|
| 金酒 | 30 ml |
| 无糖苏打水 | 140 ml |
| 蝶豆花茶 | 30 ml |
| 柠檬汁 | 10 ml |
| 糖浆 | 0–3 ml，可选 |
| 冰块 | 适量 |

### 制作步骤

1. 在高球杯中加入冰块。
2. 倒入金酒 30 ml。
3. 加入柠檬汁 10 ml。
4. 倒入无糖苏打水 140 ml。
5. 缓慢加入蝶豆花茶 30 ml。
6. 轻轻搅拌一次，观察颜色变化。
7. 如果觉得太酸，可加入少量糖浆。

### 装饰方案

- 用白卡纸制作一片羽毛形杯签。
- 杯身尽量保持干净透明。
- 不添加复杂的链条或吊坠。

### 最终效果

浅青色酒液、透明冰块和白色羽毛形成轻盈的清新感。

## 06 秧秧·玄翎｜青羽听风

这款与基础形态的秧秧有所区别。

秧秧强调轻盈，而玄翎更突出青蓝色、黑白对比和羽翼结构。

### 材料

| 材料 | 用量 |
|---|---:|
| 金酒 | 35 ml |
| 无糖苏打水 | 120 ml |
| 蝶豆花茶 | 40 ml |
| 柠檬汁 | 8 ml |
| 蓝柑橘糖浆 | 3 ml |
| 冰块 | 适量 |

### 制作步骤

1. 在透明直筒杯中加入冰块。
2. 倒入金酒 35 ml。
3. 加入无糖苏打水 120 ml。
4. 加入蓝柑橘糖浆 3 ml。
5. 轻轻搅拌均匀。
6. 沿吧勺背面加入蝶豆花茶 40 ml。
7. 最后加入柠檬汁 8 ml，观察颜色是否转为紫色。

### 装饰方案

- 用黑白卡纸制作两片羽翼。
- 两片羽翼交错固定在杯签上。
- 杯身可以使用少量青色透明胶片。
- 不必使用真正的鸟羽毛，以免卫生处理麻烦。

### 最终效果

青蓝色渐变、黑白羽翼和透明冰柱，形成比基础形态更鲜明的视觉效果。

## 07 柯莱塔｜镜金流光

**主题：金色、冰蓝、晶体、镜面反光。**

### 材料

| 材料 | 用量 |
|---|---:|
| 伏特加 | 35 ml |
| 无糖苏打水 | 130 ml |
| 无糖乌龙茶 | 30 ml |
| 蓝柑橘糖浆 | 3 ml |
| 柠檬汁 | 8 ml |
| 食品级可食用闪粉 | 极少量，可选 |
| 冰块 | 适量 |

### 制作步骤

1. 在透明古典杯中加入冰块。
2. 倒入伏特加 35 ml。
3. 加入乌龙茶 30 ml。
4. 加入柠檬汁 8 ml。
5. 倒入无糖苏打水 130 ml。
6. 加入蓝柑橘糖浆 3 ml，轻轻搅拌。
7. 如果使用闪粉，必须确认产品明确适用于食品或饮料，并严格按照产品说明使用。

### 装饰方案

- 杯外固定金色链条。
- 配合蓝色晶体吊坠。
- 尽量使用透明大冰块，突出光线折射。
- 不必把酒液调成浓烈的金黄色，金色装饰已经足够。

### 最终效果

酒液清透，杯身具有蓝金对比，金色链条和晶体吊坠营造华丽感。

## 08 绯雪｜霜华映雪

这款以冰雪和绯红对比为设计方向。

### 材料

| 材料 | 用量 |
|---|---:|
| 白朗姆酒 | 30 ml |
| 无糖苏打水 | 130 ml |
| 蝶豆花茶 | 40 ml |
| 柠檬汁 | 10 ml |
| 红石榴糖浆 | 3–5 ml |
| 冰块 | 适量 |

### 制作步骤

1. 在透明高球杯底加入红石榴糖浆 3–5 ml。
2. 加入冰块。
3. 倒入白朗姆酒 30 ml。
4. 加入柠檬汁 10 ml。
5. 倒入无糖苏打水 130 ml。
6. 最后缓慢加入蝶豆花茶 40 ml，形成冰蓝色主体。
7. 不要大力搅拌，尽量保留红蓝渐变。

### 装饰方案

- 用白卡纸制作雪花杯签。
- 使用透明冰柱表现冰晶。
- 红色只作为底层和少量点缀，不必让整杯变成红色。

### 最终效果

浅红底层、冰蓝主体和白色雪花形成冷暖对比。

# 第五部分：控制甜度的统一标准

这是整套方案需要特别注意的地方。

## 1. 糖浆只负责颜色

建议大部分单杯的糖浆总量控制在 3–8 ml 左右。

例如：

- 爱弥斯：草莓 5 ml＋蓝柑橘 3 ml。
- 达妮娅：草莓 5 ml＋蓝柑橘 3 ml。
- 心：石榴糖浆 5 ml。
- 柯莱塔：蓝柑橘 3 ml。

如果觉得颜色不够浓，优先尝试提高茶液浓度、改变灯光和背景，不要直接把糖浆加倍。

## 2. 用茶和苏打水代替甜汽水

雪碧等含糖汽水容易使酒液过甜，所以本方案主要使用无糖苏打水。

乌龙茶能够提供一定的茶香和涩感，适合与伏特加、朗姆酒搭配。

## 3. 柠檬汁负责平衡

建议先按照配方添加柠檬汁。

如果觉得酸度太高，可以适当减少；如果觉得甜腻，可以先减少糖浆，而不是无限增加柠檬汁。

## 4. 分层与口感需要取舍

有些糖浆密度较高，能够沉在杯底形成渐变，但分层并不意味着颜色一定能长期保持。

如果你更在意拍照效果，可以先完成分层，再拍照；如果更在意饮用体验，可以在拍照后轻轻搅拌，让酒液均匀。

# 第六部分：统一制作流程

如果你要一次制作八杯，我建议按照以下顺序操作。

### 阶段一：准备

1. 提前泡好蝶豆花茶并冷却。
2. 将乌龙茶冷藏。
3. 准备好八只透明杯子。
4. 制作狐耳、羽翼、剑形、雪花等杯签。
5. 准备冰块、量杯和长柄勺。

### 阶段二：制作酒液

按照配方分别量取基酒、茶液、苏打水和柠檬汁。

不要提前把八杯酒全部混在一个容器里，否则后续无法控制颜色和分层。

### 阶段三：完成颜色

根据每款配方添加糖浆或蝶豆花茶。

红色和粉色糖浆优先沿杯壁缓慢加入；需要蓝色渐变时，蝶豆花茶可以沿吧勺背面缓慢注入。

### 阶段四：固定装饰

最后再安装杯签、金色链条、蓝色吊坠和透明披帛。

装饰物应固定在杯外，避免接触饮料和杯口。

### 阶段五：拍照

建议统一使用：

- 黑色或深灰色背景。
- 柔和侧光。
- 透明玻璃杯。
- 同一高度和拍摄角度。

这样八杯摆在一起时，会更像完整的角色特调系列，而不是八杯风格各异的普通饮料。

## 三、我的最终建议

整套方案真正值得花钱的地方只有三类：

1. **少量基酒：** 负责口感和酒精度。
2. **少量糖浆与茶：** 负责颜色与基础风味。
3. **角色杯饰：** 负责让人一眼认出人物。

**如果按性价比、造型辨识度和制作难度综合排序，我最推荐优先制作：心「绯雪衔珠」、达妮娅「绯樱鎏光」、爱弥斯「电子幽灵」。** 这三款最容易通过颜色与杯饰形成鲜明的角色差异，也最适合先试做。
